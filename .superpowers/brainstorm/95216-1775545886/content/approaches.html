三种技术方案

选择最适合这个项目的架构

A

Electron + React（推荐）

用网页技术构建 Mac 桌面应用。React 负责 UI，Node.js 处理 API 调用和定时任务，electron-builder 打包成 .app 文件。

优势

  • 开发速度快，UI 组件库丰富
  • OAuth 登录、HTTP 调用生态成熟
  • 可打包为标准 Mac .app
  • TypeScript 保证代码质量

劣势

  • 安装包较大（~150MB）
  • 非原生 Mac 外观
  • 内存占用比原生高
B

SwiftUI 原生 Mac App

使用苹果官方框架开发，外观与系统完全一致，性能最佳。后端逻辑用 Swift 实现。

优势

  • 原生 Mac 外观与体验
  • 安装包小、性能最好
  • 系统通知、菜单栏集成最佳

劣势

  • 开发周期更长
  • 第三方平台 API 库少，需手写
  • 复杂 UI 排版比 HTML 麻烦
C

Python 后端 + 本地 Web UI

Python FastAPI 作为本地服务，浏览器作为 UI。无需安装，访问 localhost 即可使用。

优势

  • Python 生态对 AI 集成最友好
  • 开发灵活，调试方便
  • AI 相关库（LangChain 等）直接用

劣势

  • 不是真正的 Mac App
  • 需要在终端启动服务
  • 用户体验不如桌面应用

系统架构

各模块职责与数据流向

⚙️ 内容生成层
• Claude API
• 批量自动生成（cron）
• 手动指定歌名生成
• 生成后入"待审"队列
✍️ 审查编辑层
• 内容预览与富文本编辑
• 选择发布平台
• 设定发布时间
• 通过 / 拒绝 / 重新生成
🚀 发布层
• 定时任务调度（node-cron）
• 微信公众号 API
• 今日头条 API
• 可扩展更多平台
↕ ↕ ↕
🗄️ 本地数据库（SQLite）
内容状态（待审 / 已通过 / 已发布 / 已拒绝） · 平台账号 Token · 发布记录 · 自动生成计划
🖥️ Electron 壳 + React UI
Dashboard · 待审队列 · 编辑器 · 发布历史 · 设置（平台账号 / AI 参数 / 自动计划）
数据流
生成器 → SQLite（待审） → 用户审查/编辑 → SQLite（已通过+定时） → node-cron 触发 → 平台 API → SQLite（已发布）
✅ MVP 包含
公众号 + 今日头条 · 内容生成与审查 · 定时发布
🔮 后续可扩展
视频号 · 抖音 · 小红书 · 视频生成
